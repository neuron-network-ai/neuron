# NEURON coordinator — dependencies (lightweight; NO torch/transformers).
# The coordinator is pure FastAPI + SQLite (stdlib) + a small HTTP client.
# Runs on any tiny always-on VM (~1GB RAM, ARM or x86).
#
# Tested with: fastapi 0.139.2, uvicorn 0.51.0, requests 2.34.2
# (versions left open for portability; pin these if you want reproducible deploys).
fastapi
uvicorn[standard]
requests

# Payout address binding (coordinator/payout.py) — recovers the signer of a node's
# proof-of-control signature. Still no torch: eth-account is pure Python plus small wheels.
# Imported lazily, so a coordinator without it starts fine and only payout binding fails.
eth-account

# The [P52] wire encryption (security/wire_crypto.py), which router.py imports at MODULE
# SCOPE — unlike eth-account above, so its absence is not a degraded feature, it is a
# coordinator that cannot start at all. On 2026-08-19 a deploy without it put the live
# service into a systemd restart loop: ModuleNotFoundError, /status 502, the whole network
# unroutable, and `systemctl is-active` still answering "activating" while it happened.
# If router.py ever stops importing this eagerly, this line still stays — the grant minting
# needs it either way.
cryptography
