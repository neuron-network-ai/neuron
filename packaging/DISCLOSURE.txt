Before you install NEURON, four honest things:

1. NRN HAS NO CASH VALUE.
   NRN is a contribution credit, not money. It records the compute you gave the
   network and — per the project roadmap — what you'll spend to run your own AI
   queries later. Please don't install this expecting to earn income. The
   electricity your machine uses while donating compute is worth more than the
   NRN you'll earn for it; think "fund my own AI usage," not "make money."

2. WINDOWS MAY WARN YOU ABOUT THIS INSTALLER.
   This app is not yet code-signed (that requires a paid certificate NEURON
   doesn't have yet), so Windows SmartScreen or your antivirus may show an
   "unrecognized app" warning. That is expected for any unsigned open-source
   app, not a sign something is wrong. You can read every line of the source
   at https://github.com/neuron-network-ai/neuron before trusting it.

3. WHAT THIS APP ACTUALLY DOES.
   It downloads a small slice of an AI model (~1 GB), uses ~1-2% of your CPU
   only while your machine is idle (it pauses the moment you start using it,
   and on battery), and relays inference requests for the network. It sends
   the coordinator only a node ID, the layer range it serves, and CPU/RAM
   counts — no personal data. Uninstalling removes everything, including the
   downloaded model slice.

4. PRIVACY, AND IT GOES BOTH WAYS.
   Your machine sends only a node ID, its layer range and CPU/RAM counts. Never
   your files, your browsing or your screen.

   It RECEIVES numbers made from other people's prompts, and computes on them.
   You cannot read those: your machine holds a middle slice of the model, not
   the parts that turn text into numbers or back again. The same is true of
   everyone else's machine holding a slice of yours.

   If you also use the chat: when the model fits on your PC the answer is
   computed here and your text never leaves. Over the network every link is
   encrypted — including from NEURON's own coordinator. Two exceptions, both
   named: switching on web search sends that query to DuckDuckGo, and a prompt
   blocked by the safety filter reports its category (never the text).

   Full detail, naming the file behind each claim: PRIVACY.md

Click Next only if you're comfortable with the above.
