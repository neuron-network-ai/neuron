How it works

An AI model is a stack of layers, and a big one needs more memory than any ordinary computer has. NEURON splits that stack across several machines: yours holds a few layers, someone else holds the next few. Together they run a model none of them could run alone.

Only your own machine ever reads what you type. It holds the part that turns text into numbers and back again. Every other computer in the chain receives anonymous numbers and has no way to read them — that is a property of how the work is split, not a promise anyone has to keep.

While you are not using your computer, it helps run the network and earns NRN for the work it contributes. NRN is a record of compute contributed — it has no cash value, there is no exchange and no sale, and we would rather say so here than have you find out later. Your node pauses the moment you touch the keyboard, and on battery.

What you need

  • Windows, Linux or macOS
  • 4 GB or more of free RAM
  • No GPU required — though an NVIDIA card with CUDA is used automatically if you have one
  • No crypto wallet
  • No payment details, and nothing personal collected
